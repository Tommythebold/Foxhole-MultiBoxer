# Foxhole MultiBoxer

Foxhole MultiBoxer is an AutoHotkey tool for managing multiple Foxhole accounts and game windows.

Features include:

- Multi-account Steam/Foxhole launching
- Sandboxie support
- Sequential login workflows
- Rebindable multibox hotkeys
- Train Slow, auto-click, key/mouse hold controls
- Per-account targeting
- Saved multi-monitor window layouts
- Window overlays and taskbar handling
- Automatic update notifications
